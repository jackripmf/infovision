# Ежедневные товарные остатки

Тестовое задание InfoVizion: расчёт остатков на конец каждого календарного дня по паре `item_id + location_id`.

```text
остаток на конец дня = остаток предыдущего дня + сумма движений за день
```

Движения по одинаковому товару, подразделению и дате сначала суммируются. Новая пара товар–подразделение начинает расчёт с нулевого остатка, а дни без операций получают остаток предыдущего дня.

## Запуск

Python 3.10+, сторонние зависимости не требуются.

```bash
python stock.py --target-date 2025-07-31
```

## Особенности реализации

- `Decimal` для количества и стоимости без погрешности `float`;
- валидация структуры CSV, дат, чисел и обязательных значений;
- корректная агрегация повторных движений;
- атомарная запись через временный файл;
- стабильная сортировка по товару и подразделению.

## Тесты

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют суммирование движений, перенос остатка через дни без операций, появление нового товара, целевую дату и контроль дублей.
